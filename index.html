PRIVATE BY DESIGN

Bring in a statement

Your statement is read in your browser and never uploaded. PDFs are decoded locally with Mozilla's PDF.js, which is fetched from a CDN the first time — the file itself stays on this device.

↑ Choose a statement file PDF, CSV, TSV, OFX, QFX or QIF · up to 25 MB

Works with Indian bank statements (date / remarks / withdrawal / deposit / balance) and credit-card statements (date / details / amount with Dr-Cr). Scanned, image-only PDFs need OCR and are not supported. Always reconcile imported totals against the original statement.

One-time setup
  1. Create a free project at Supabase.
  2. In Supabase, open SQL Editor → New query and run the setup SQL in the README.
  3. Copy the Project URL and publishable/anon key from Project Settings → API.

YOUR PRIVACY

Private by default

01
Files stay on your device

Statement files are parsed locally in your browser. Stillwell has no server and never transmits or retains your original files.

02
Data stays in this browser

Accounts and parsed transactions are saved in this browser. If you enable Sync, they are also stored in the Supabase project you configure. Use a private, trusted device.

03
No bank connections

There are no integrations, credential prompts, or automatic balance updates. You control every number.
