PRIVATE BY DESIGN

Bring in a statement

Your statement is read in your browser and is not uploaded. For PDFs, PDF.js loads from jsDelivr to extract text; the statement itself stays on this device.

↑Choose a statement fileCSV, TSV, OFX, QFX, QIF or text-based PDF · maximum 10 MB

CSV headers such as Date, Description, Debit, Credit, Amount, or Category are recognized. Text-based PDFs are extracted locally with PDF.js; scanned/image-only PDFs need OCR and are not supported yet. Statement layouts vary, so review imported rows before relying on a report.

One-time setup
  1. Create a free project at Supabase.
  2. In Supabase, open SQL Editor → New query and run the setup SQL in the README.
  3. Copy the Project URL and publishable/anon key from Project Settings → API.

Your financial data will be stored in the Supabase project you configure. The app uses private per-user access policies. GitHub hosts the site files only.
YOUR PRIVACY

Private by default

01
Files stay on your device

Statement files are processed locally in your browser. Stillwell has no server and does not transmit or retain your original files.

02
Data stays in this browser

Accounts and parsed transactions are saved in this browser. If you enable Sync, they are also stored in the Supabase project you configure. Use a private, trusted device.

03
No bank connections

There are no integrations, credential prompts, or automatic balance updates. You control every number.
